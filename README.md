PyMentor Bot 🐍

PyMentor — это бот для ВКонтакте, который помогает пользователям изучать язык программирования Python прямо в диалоге с сообществом. Бот подходит как новичкам, никогда не писавшим код, так и тем, кто хочет углубить знания и попрактиковаться в решении задач. После запуска бот предлагает пройти короткий тест, чтобы определить текущий уровень пользователя и подобрать подходящую программу обучения. Материал разбит на тематические модули — от основ синтаксиса и типов данных до работы с функциями, ООП и стандартными библиотеками. По каждой теме бот присылает краткую теорию, примеры кода и практические задания с автоматической проверкой решений. Ответы пользователя анализируются, и в случае ошибки бот объясняет, что пошло не так, и даёт подсказку, а не просто готовое решение. Встроена система прогресса: бот запоминает пройденные темы, набранные баллы и предлагает повторение забытого материала. Для закрепления знаний доступны мини-викторины и еженедельные челленджи с несложными алгоритмическими задачами. Пользователь может задать боту вопрос по конкретной теме или синтаксической конструкции и получить объяснение простым языком. Бот умеет напоминать о регулярных занятиях, если пользователь давно не заходил, чтобы поддерживать привычку учиться. Взаимодействие происходит через личные сообщения сообщества ВКонтакте с использованием клавиатур и кнопок для удобной навигации по меню. Бот реализован на базе VK Bots API (Long Poll) и легко расширяется новыми темами и заданиями
